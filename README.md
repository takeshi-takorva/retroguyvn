# RetroGuy Website V1

Official website source for RetroGuy VN and the Digital Realm project.

## Stack

- Astro
- Cloudflare Workers / Static Assets
- TypeScript
- GitHub-based deployment

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Cloudflare deployment

```bash
npm run deploy
```

The first public release focuses on product storytelling, Digital Realm features, media, news, downloads, and support. Backend services such as account, OTA, cloud save, and online PvP are intentionally separated for later phases.
