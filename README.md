# RetroGuy Website

Official website and Cloudflare backend source for RetroGuy VN and the Digital Realm project.

## Stack

- Astro
- Cloudflare Workers / Static Assets
- Cloudflare D1
- Cloudflare R2
- TypeScript / JavaScript modules
- GitHub-based deployment

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm test
npm run build
```

`npm run build` also performs a Wrangler dry-run and validates production bindings generated by Astro.

## Cloudflare deployment

```bash
npm run deploy
```

Do not deploy the Digital Realm OTA milestone until the dedicated `retroguyvn-firmware` R2 bucket exists and D1 migrations have been applied to the existing `retroguyvn-db` database.

OTA operator guide:

- `docs/DR_OTA_CLOUDFLARE.md`
- `docs/DR_OTA_SECURITY.md`

OTA admin workspace after deployment:

```text
https://retroguyvn.com/admin/ota
```

Device endpoints remain fixed at:

```text
GET https://retroguyvn.com/api/dr/ota
GET https://retroguyvn.com/api/dr/ota/download
```

The website/CMS, OTA firmware service, and future online services share the Worker deployment while keeping their storage and route responsibilities isolated.
